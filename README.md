# مشغل الصوت — Audio Player

مشغّل صوتيات للملفات المحلية مبني بـ Flutter، بتصميم زجاجي مستوحى من أحدث iOS، ويعمل على جميع أنظمة التشغيل.

A cross-platform Flutter player for local audio files with an iOS-inspired "liquid glass" design.

## المميزات

- **مكتبة الصوتيات:** كل الصوتيات أو حسب المجلد، مع بحث (بالاسم أو الفنان) وترتيب بالتاريخ أو الاسم.
- **المشغّل:** أسطوانة تدور أثناء التشغيل وتحمل صورة الأغنية إن وُجدت، وشريط تقدّم، وسرعة تشغيل، وتكرار، وتشغيل عشوائي، ومؤقت نوم (بمدة أو عند نهاية المقطع، مع خفض تدريجي للصوت).
- **المشغّل المصغّر:** السابق / تشغيل / التالي مع الوقت المنقضي والمدة.
- **التشغيل في الخلفية** مع إشعار وأزرار تحكم، وإيقاف تلقائي عند فصل السماعات.
- **تحديد متعدد:** ضغطة مطوّلة لتحديد عدة صوتيات وحذفها أو مشاركتها معاً.
- **الحذف من الجهاز فعلاً:** على أندرويد 11+ عبر نافذة النظام (مرة واحدة لكل المحدد)، وعلى الماك إلى سلة المهملات.
- **تعيين كنغمة** على أندرويد، ومشاركة، وتفاصيل الملف.
- **الماك:** عرض بعمودين (المكتبة + المشغّل)، واختصارات لوحة المفاتيح (Space، الأسهم، ⌘ + الأسهم).
- **العربية والإنجليزية**، والوضع الداكن والفاتح.

## التشغيل والبناء

```bash
flutter pub get
flutter run                 # جهاز متصل أو -d macos

# أندرويد: ملف لكل نوع معالج (أصغر بكثير من ملف واحد شامل)
flutter build apk --release --split-per-abi --obfuscate --split-debug-info=build/debug-symbols

# الماك
flutter build macos --release
```

- `app-arm64-v8a-release.apk` للهواتف الحديثة (64-bit)، و`app-armeabi-v7a-release.apk` للهواتف القديمة (32-bit).
- احتفظ بمجلد `build/debug-symbols` مع كل إصدار لقراءة تقارير الأعطال.
